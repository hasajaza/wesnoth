WESNOTH ACCESS @ACCESS_VERSION@
Battle for Wesnoth @GAME_VERSION@ for blind players, with JAWS, NVDA or SAPI speech.
Build commit: @REVISION@

Start here:
  INSTALL.txt               installing, starting, if there is no speech, removing
  MANUAL.txt                how to play
  KEYS.txt                  all keys (also F2 in the game)
  TESTING-CHECKLIST.txt     test list for JAWS and NVDA
  KNOWN-LIMITATIONS.txt     what is not done or not yet tested
  FEATURES.txt              feature status
  CHANGELOG.txt             changes
  COMMAND-IDS.txt           names for changing keys
  ARCHITECTURE.txt          technical description

Quick start: run Install.cmd, then start the "Wesnoth Access" shortcut.
Press F2 in the game for the command list, Shift+F2 for settings.
